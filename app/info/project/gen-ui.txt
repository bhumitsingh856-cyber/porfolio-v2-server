AI-powered frontend generator that turns a text description into a complete, production-ready React application — with live preview 

✨ What is GEN UI?
GEN UI generates a fully working React application with real components, animations, and styles. No templates. No drag and drop. Just code.

🚀 Features
AI Code Generation — Fireworks AI generates complete React apps at 400 tokens/sec upto 32k tokens.
Instant Preview — Sandpack renders your app in the browser with zero setup
File Explorer — Full component tree with syntax-highlighted code viewer
AI Assistant for file updation — chat with ai 
Live link — Opens a live shareable URL in CodeSandbox instantly
Export as ZIP — Download your generated project and run it locally
Split View — Side-by-side code editor and live preview
Persist generation in mongodb and access projects anytime

💡 Highlights:
• Generates full multi-file frontend projects.
• Clean project structure with components.
• Integrated editor with real-time preview.
• AI-based error correction.
• Downloadable code 
• Live shareable link
• UI Assistant for file updation
